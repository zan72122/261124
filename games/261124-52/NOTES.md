# だんボールひこうき（261124-52）

元ネタ：Diana and Roma 2026年10月の回（10/07 飛行機）のごっこ遊び。主役の素材は段ボール。

## 作ったもの
three.js（r160 を同梱）で作った3Dの庭。文字・数字は一切なし、指1本で遊ぶ。

0. **制服を着る**：箱の上の機長の帽子と紺の制服を、女の子にドラッグ（タップでもOK）。着ると敬礼して紙吹雪。
1. **飛行機をつくる**：段ボールの胴体のまわりに翼2枚・尾翼・プロペラが落ちている。光る点線の場所へ運ぶとパチッとはまり、ぐらぐらしている所をタップするとカラーテープを「ビビーッ」と貼る。違う場所に置くとボヨンと戻って女の子が「あれ？」顔。
2. **空港の検査**：くま・うさぎ・いぬのぬいぐるみが順番に来る。パスポートをタップで開き、ハンコをポン。カバンを検査機に送ると**カバンが透けて**中身が水色の影になり、お菓子だけが色つき＋禁止マークで光る。
   - 1人目はパパが張り切って先にボタンを押す → ブーッ、赤ランプ、パパがすべって後ろにずっこけ目を回す（ルールを見せる大人の失敗ギャグ）。
   - パパをタップすると起き上がり、看板（お菓子に禁止マーク）を指さす。お菓子をタップして取り出すとピンポン。
   - お菓子を入れたまま緑のボタンを押すと、何度でもブーッ＆パパがずっこける（失敗ではなくギャグ）。
3. **離陸・ジュース・着陸**：操縦席で操縦かん（キッチンペーパーの芯）を倒すとプロペラが回り、**段ボール飛行機が庭から空へ**。客室ではワゴンのジュースを乗客へ。吹き出しの絵がほしい飲み物。違う物を渡すと「あれ？」顔のあと喜んで飲む。1杯ごとに窓の外が 雲の中 → 海 → 島 と変わり、3杯で島の段ボール滑走路に着陸。
4. **自由に飛ぶ（おわりなし）**：飛行機をタップで再離陸。指を上下に動かすと高度が変わり、風船に当てるとパン！飛行機タップで宙返り、イルカをタップで大ジャンプ。左上のボタンは1秒長押しで最初から。

## 判断の記録
- **文字なしの伝え方**：次に触る物は5秒ほど何もしないと白い手のアイコンが動いて示す。目標地点は点線リング・半透明のゴースト。
- **カメラ**は場面ごとに固定のショットへ自動で寄る。画面の縦横比に合わせて「必ず見せたい幅と高さ」が入るよう画角を自動調整（縦持ちでも全体が入る）。
- **歩くアバターなし**。女の子は指の先を目で追い、手を伸ばし、表情（にこ・わーい・あれ？・びっくり・集中）で反応する。
- **やらかし役はパパ**（検査で転ぶ）。娘がパパをタップして起こす＝立て直し。
- **写実寄りの質感**：段ボールの表面は写真テクスチャ（画像生成→縮小・波目を弱めた加工）＋凹凸マップ、PBR＋環境光＋影。芝・デッキ・壁・海はキャンバスで生成。キャラはぬいぐるみ/人形風の柔らかい形にして怖さを避けた。
- お姫様・おばけ・実在キャラ・ブランドは出さない。パスポートや看板も絵と記号だけ。
- 音はすべて WebAudio で合成（テープ、ハンコ、ブザー、エンジン、BGM）。外部ファイルは three.js とテクスチャ2枚のみ。
- 共通ロガー `../../gf-playlog.js` を読み込む（このフォルダ単体では404でも動作に影響なし）。
- デバッグ用に `?scene=1..3`（途中から）と `?ts=倍率`（時間加速）を残してある。
