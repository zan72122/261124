# 261124-54 レストランとホテルのてんいんさん

元ネタ: Diana and Roma 2026/10/14「レストランとホテル」のごっこ遊び。
主役の素材: 白いテーブルクロス（リネン）と真鍮（ベル・ランプ・カート・蛇口）。

## 流れ（5場面・文字なし）
0. **きがえ** — フックのエプロン、テーブルのコック帽をタップ → 女の子が着て一回転・バンザイ（この瞬間の顔を写真として撮っておく）。真鍮のベルが出て、鳴らすと開店。
1. **レストラン** — 空のテーブルに家族と近所の人が入ってきて座り、頭の上に料理の絵。カウンターの3台（鍋・フライパン・まな板）を3回タップで料理ができる。ドラッグでも「タップ→お客さんタップ」でも運べる。
   - パパが最初の一皿で必ずこぼす（大人の失敗）。カメラが寄り、ふきんが出る → こすって拭くとパパが喜び、もう一度スープを頼む。
   - 全員食べたらデザート。ケーキにいちご・クリーム・ブルーベリー・スプリンクルを載せ、ケーキをタップすると全員に一切れずつ配られ、満席でにこにこ＋拍手＋紙吹雪。
2. **ホテルのフロント** — お客さんが真鍮のベルを鳴らし、鍵の絵（アヒル・花・星のタグ）を思い浮かべる。鍵を渡す → スーツケースをタップ → 真鍮のカートに載って部屋へ。2人目のおじいちゃんはベルを3回鳴らす。
3. **おふろ** — 蛇口でお湯、ピンクのボトルで泡の素。両方そろうとおじいちゃんが飛び込み、泡が山になって顔と泡の帽子・泡のひげだけ出る（ギャグ）。泡をタップ／こすって割るとアヒルが落ちてきておしまい。
4. **庭のトランポリン** — 人をタップすると乗る。トランポリン（どこでも）をタップすると次のジャンプが高くなり、最高段で腕をパタパタ回転して「飛ぶ」。パパは初回のてっぺんで尻もち。4人とも飛んだら壁の額に場面0で撮った女の子の写真が飾られ、全員拍手。その後は女の子も乗れる自由遊び（右上の円矢印でもう一回）。

## 判断メモ
- **写実の作り方**: Three.js（同梱、外部CDNなし）＋ PBR・ソフトシャドウ・環境光。床・壁・リネン・大理石・芝・タイル・レンガ、窓の外・庭の背景は Stability API で生成したテクスチャ写真（`tex/`、端をなじませてタイル化）。人物は写実に寄せると不気味になるので、顔をキャンバスで描く人形風にして、表情（にこ・あれ？・びっくり・あちゃー・もぐもぐ・大笑い）で話を伝える。
- **「あれ？」ルール**: 違う料理・違う鍵でも、首をかしげて「ん？」の音のあと喜んで受け取る。失敗なし。絵の看板（吹き出し→矢印→にこにこ）を1枚だけ壁に。
- **ヒント**: 6.5秒さわらないと次に触る物がぴょこっと弾んで光る。
- **当たり判定は甘め**: 見えない大きめの当たり箱＋外れても近くの物を拾う。運ぶ先は画面上で近ければOK。
- **カメラ**: 場面の入りでゆっくり寄る、こぼした時・デザート・写真で自動で寄る。プレイヤーは動かさない。
- 音はすべて Web Audio で合成（ベル・ポン・ボヨン・ジャー・拍手・ファンファーレ・BGM）。最初のタッチで音が有効になる。
- スマホ縦持ちでは上に「横にしてね」の絵だけ出す（遊べはする）。
