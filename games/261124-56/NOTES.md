# 261124-56 ピンクとブルーのプール

5歳向け・指1本・文字なしの3Dプールごっこ。元ネタは子ども向け動画（10/21 プール回）のごっこ遊び。

## 作ったもの
- **はじまり（着替え）**: 女の子の前にピンクとブルーの水泳帽が浮かぶ。タップした色の帽子と水着になり、その色が「自分の色」になる。男の子は反対の色。
- **場面1 ボールでプールを染める**: プールの水面をタップ → 女の子がその場所へ自分の色のボールを投げる。男の子も反対の色を投げてくる。
  - 色対決だけで終わらせない仕掛け: 男の子をタップすると自分の色のボールを手渡す → 「あれ？」の顔 → 帽子と服が自分の色に変わって仲間になり、一緒に投げてくれる。
  - 自分の色が一定数たまると、残りのボールが中心から順に自分の色へ反転し、プールの水も一色に染まる（大きな変化）。紙吹雪のあと、ボールは全部カゴへ片付けられる。
  - ルール見せ: 絵の看板（ボール→プール）＋パパのギャグ（ボールを真上に投げて頭にゴツン→プールにポチャン）。
- **場面2 おもちゃが本物に**: デッキに並んだおもちゃ（イルカ・タコ・アザラシ・カニ）をタップ → プールに投げ入れると光って本物サイズ・本物の色に変わり泳ぎ出す。
  - イルカはジャンプ、タコは噴水、カニはデッキを横歩き、アザラシはデッキチェアに上がって寝る（いびき＋泡）。
  - ゴール: 4匹とも本物になり、アザラシが寝たら完成。パパがデッキチェアに座ろうとして「あれ？」→笑う、で締め。
- **場面3 流れるプールで浮き輪を配る**: パパが浮き輪を全部かかえて流れるプールへ飛び込み、遠くへ流されてしまう（大人のやらかし）。
  - パパの浮き輪をタップ → 女の子が頭の上に持つ → 待っている人（ママ・アザラシ・タコ・カニ・男の子）をタップして渡す。吹き出しの絵がほしい浮き輪。違う物を渡すと「あれ？」の顔→汗のしずく→結局喜ぶ。
  - 1つ配るごとにパパが流れに乗って戻ってくる。全員に配るとパパが岸に戻り、最後の浮き輪を女の子にくれて、みんなで流れるプールへ。
  - 最後は自由遊び: みんなが浮き輪で流れる。人や生き物をタップ→ジャンプしてくるり、すべり台の塔をタップ→ピンクとブルーのボールが滑ってくる、水面タップ→ボールがポンと浮かぶ、イルカをタップ→ジャンプ。右上の丸い矢印で最初から。

## 判断の記録
- **写実寄りの見た目**: 家の庭・ウォーターパークは画像生成AIで写真風の背景と石畳・タイル・芝のテクスチャを作り、3D（three.js、PBR、ACES、影、環境反射、水面の波・コースティクス）と合わせた。人物は表情を読ませるため顔だけ大きめの人形寄り。実在の作品のキャラは使わず、家族は汎用の女の子・男の子・ママ・パパ。
- **カメラ**: 場面ごとに決めたショットへ自動でなめらかに移動。画面の縦横比から距離を決めるので iPhone 縦でも iPad 横でも主役が切れない。
- **指＝女の子の手**: タップした場所・相手に向かって女の子が振り向いて投げる・渡す。タップ判定は画面上で半径を広めにとり、小さな指でも当たるようにした。
- **失敗なし**: 違う浮き輪も受け取ってもらえる。最後の浮き輪は必ず女の子のもとへ。5秒ほど何もしないと、次に触る物の上に指のアイコンが出る。
- **文字なし**: 画面上は絵とアイコンだけ（看板も絵）。音はWebAudioで合成（声は母音の音色だけで言葉なし、BGMは小さめ）。
- **ファイル**: `index.html`, `game.js`, `three.module.min.js`（r170、ネット不要で動くよう同梱）, 背景・テクスチャ画像。`?debug&stage=2` などでテスト用に場面へ直行できる。
