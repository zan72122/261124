# 261124-57 ピンクのアイスクリームトラック

元ネタ: Diana and Roma 2026/10/24「アイスクリームトラック」回のごっこ遊び。
5歳・文字なし・指1本（タップ中心、拭く場面だけこすってもOK）。

## 流れ（各場面に小さなゴール → 次へ）
0. **着替え** 庭で、ラックの帽子とエプロンをタップ → 画面の女の子が店員さんになる（くるっと回って紙吹雪）。
1. **トラックを組み立てる** 芝生に小さなピンクのふわふわ部品（車体・運転席・アイスの看板・窓・タイヤ4つ）。
   タップ（または白い影をタップ）すると飛んで大きくなり、所定の位置にはまる。順番は自由。
   全部はまったら窓が光る → タップで窓が開いてお店になる → お客さんが歩いてきて**行列**ができる。
2. **お店** トラックの中から。お客さんの頭の上の吹き出しに欲しいアイスの絵。
   コーン → ショーケースの4色をすくう（最大3段）→ ソース2種 → トッピング2種 → コーン（かお客さん）をタップで手渡し → レジでピッ、コインがチャリン。
   - 違う物を渡すと「あれ？」の顔（眉・汗・首かしげ＋上がり調子の音）をしてから喜ぶ。失敗なし。
   - 2人目の男の子がアイスを落とす → スポンジが出る → タップ／こすって拭く → 作り直し。
   - 3人目のとき、ねじ巻きの丸いてんとう虫のおもちゃがアイスに乗る → タップでぴょんと退場（もしくは手渡しで自分から跳ぶ）。
   - 最後のお客さんはパパ（3段・いちごソース・さくらんぼ）。
3. **プール** 「走らない」の絵の看板（走る人＋赤い丸と斜線、文字なし）。パパが看板を無視して走り、水たまりでつるっ → ドボン、アイスが頭に逆さまに乗る。
   娘が立て直す: 浮き輪を投げる → パパを引き上げる → 頭のアイスを取ってあげる。パパは看板を指さして、つま先歩きで反省。
   → 画面が四角いタイルで切り替わり **ブロックの世界**（最後・終わりなし）。下のパレット（スコップ＋7色のブロック）を選んで、
   ブロックをタップで掘る／積む。ブロックのピンクのトラックの窓をタップするとブロックのアイスが飛び出す。ブロックの娘とパパが歩き回り、タップで跳ねる。

## 判断の記録
- **写実感**: Three.js（同梱、CDN依存なし）＋PBR・環境光・影。庭とプールの背景写真、芝、ふわふわ素材は Stability AI で生成（人物・文字なしで生成）し、円筒の背景に貼った。
  キャラクターは写実にすると不気味になりやすいので、写実的な世界に置いた丸い人形風にし、表情はキャンバスで描いた顔テクスチャで切り替える。
- **主役素材**: トラック・看板・帽子・スツール・レジ・浮き輪・ブロックまで、ピンクのふわふわ（毛皮テクスチャ＋bump＋sheen）で統一。
- **カメラ**: 場面ごとに固定ショット。縦長画面でも収まるよう、幅と高さから距離を自動計算（縦向きでは部品の並びを詰める）。
- **ヒント**: 3.5秒触らないと、次にやるとよい物の上に指マークが出る（文字の代わり）。答え通りでなくても進める。
- **ブロック世界**: 実在ゲームに似せないよう、角の丸いパステルのブロック・草土の模様なし・ブロックの人形は独自デザイン。
- **怖くない虫**: てんとう虫は「おもちゃ」と分かるよう、ねじ巻きの鍵が回り、目が大きく、笑い声で動く。
- 音はすべて WebAudio で合成（メロディはオリジナル）。声のかわりに音程で喜び・「あれ？」・悲しみを表現。
- デバッグ用: `?s=truck|shop|pool|blocks` でその場面から、`?fast` でヒントがすぐ出る。
