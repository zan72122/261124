# 261124-58 ふしぎな きょうしつ（3つのふしぎな教室）

元ネタ: Diana and Roma 2026-10 の回（10/28 幼稚園ごっこ）。主役の素材は スライム・ブロック・風船。

## 作ったもの
文字・数字なしの 3D ごっこ遊び。指はピンクのワンピースの女の子の「手」として働き、女の子は表情で反応する。

| 場面 | すること | ゴール |
|---|---|---|
| 0 玄関 | 黄色い園の帽子とカバンを女の子へ（ドラッグでもタップでも） | 両方着たらくるっと一回転 |
| 1 ロッカー | 帽子とカバンを ★ のロッカーへ。友だち3人が順に登園 → タップであいさつ | しまう＋3人にあいさつ |
| 2a スライムの教室 | 壁がピンクに垂れ、机にスライムが落ちてくる。引っぱると伸びて、ちぎれる。のし棒でのばせる | ちぎった3つを友だちのお皿へ |
| 2b ブロックの教室 | 壁と机が積み木に。タップで崩れる → 床の積み木をタップで塔へ | 5段積んで吊るした星に届く |
| 2c 風船の部屋 | 積み木が風船に変わり部屋を満たす。指でかき分ける。友だちが隠れていて「ばあ」 | 隠れた緑のくだもの3つ（キウイ・りんご・ぶどう） |
| 3 パーティー | 風船は天井へ。くだもの→ピッチャー → ぐるぐる混ぜる → コップに注ぐ | 全員に注いで乾杯 → 以後は飲む・注ぐ・乾杯・風船割りを好きなだけ |

- 大人のやらかし: 先生役のママがコップを掲げすぎて緑のジュースを顔にかぶる（カメラが寄る）。みんな大笑い → タオルが出てきて女の子が拭いてあげる。拭くまで次へ進まない（娘が立て直す役）。
- 「あれ？」ルール: ちがうロッカーに入れると、そのロッカーの子（来ていなければ女の子）が首をかしげてから笑い、物は ★ へ跳んでいく。失敗・ゲームオーバーなし。
- 絵の看板1枚: パーティーで壁に「緑のくだもの → ピッチャー → 乾杯」の絵。
- ヒント: 4.5秒さわらないと、白い輪が次にさわる物の上に出る（ドラッグ先・ぐるぐるも動きで示す）。

## 判断メモ
- **同じ教室が変身する構成**にした。玄関とは別に教室を1つ作り、壁の材質・色・テクスチャを素材ごとに変える（ピンクの光沢→積み木柄→元に戻って風船）。「いつもの教室が一変する」をそのまま見せるため。
- 素材の受け渡しでつなげた: スライムが溶ける → 積み木が降る → 積み木が1個ずつ風船にポン → 風船が天井に浮いてパーティーの飾りになる。風船の中で見つけたくだものがジュースの材料になる。
- 写実寄り: Three.js（r170 同梱、CDN 不要）、PBR マテリアル、RoomEnvironment の環境光、ソフトシャドウ、ACES トーンマップ、木目床などはキャンバスで生成。人物は丸みのある人形風（顔はキャンバスに描いて表情を差し替え）。
- 物理は自作の軽いもの: スライムは頂点ばね変形、積み木は簡易剛体（床だけ衝突）、風船 270 個は球どうしの押し合い＋指の「レイ」から押し出し（画面の奥までトンネルができる＝かき分ける感触）。
- 音はすべて WebAudio で合成（言葉の音声はなし。笑い声・「ん？」も母音フォルマントの合成）。iOS のマナーモード対策に `navigator.audioSession.type = 'playback'`。
- カメラは自動のみ。縦長画面では FOV 上限を超えたら後ろへ下がって全体を入れる。
- 怖い物・お姫様・実在キャラ／ブランドなし。積み木はポッチのない木の積み木にした。
- デバッグ用に `?scene=lockers|slime|blocks|balloons|party` で途中から始められる（`window.__game.hint()` でヒント位置が取れ、テストではこれを追うボットで最後まで自動で通した）。
- 本番の遊戯ログ `/gf-playlog.js` を読み込む（ローカルでは 404 で無害）。
