# 261124-59 おうちに来たロボット

5歳向け・文字なし・指1本の 3D ごっこ遊び。元ネタ回（ロボットが届く）の流れを3場面＋自由遊びにした。

## 流れ
0. **着替え**: 段ボール箱の上の帽子3つ（銀のヘルメット／段ボール帽子／オレンジの帽子）。どれをタップしても女の子がかぶり、その子が「ロボット係」になる。数秒で次へ。
1. **箱が届く**: チャイム → パパがわれもの注意の絵の箱をよろよろ運ぶ → テープを貼ったままフタを引っぱって尻もち（ルールを見せる大人の失敗ギャグ）。テープ3本を指でなぞってはがす（順番自由）→ フタ4枚をタップ → 箱の中でたたまれていたロボットが起動して飛び出し、手を振る。
2. **かくれんぼ**: 目かくし → 弟が隠れる → ロボットのスキャン画面（家が青く透けて、隠れた物がオレンジに光る）。光っている所をタップ。テディ・ボールの場所だとロボットは「あれ？」の顔→笑顔。3回見つけたらゴール。
3. **お皿洗い → 泡の海**: シンクのお皿を指でこする（汚れが消える）→ タップでロボットに手渡し、ロボットが拭いて棚へ。アヒルを渡すと「あれ？」→ 頭にのせる。2枚渡すとパパが洗剤を全部入れて（やらかし）ロボットがエラー、泡が台所にあふれ、パパは泡ですべって泡帽子。指でなでて泡を割る → 残りは排水口へ渦で流れ、床がピカピカに光る（大きな変化）。
4. **新しい箱 → 自由遊び**: 小さい箱を3回たたくと小さいロボットが出てくる。ラジオでパーティ音楽＋全員ダンス、ロボット・人・箱・ロボットが吹くシャボン玉はいつまでもタップで遊べる。左上の矢印を長押しすると最初から。

## 判断メモ
- 3D は three.js r180 を `lib/` に同梱（CDN 不要・オフラインでも動く）。素材の写実感は PBR（環境マップで銀色がちゃんと映る）と、Canvas で描いた段ボール・木の床・タイル・ヘアライン加工のテクスチャで出した。画像生成 API はクレジットの残りが少なかったので使っていない。
- 人物は表情が読めることを優先して、粘土人形風の体＋描き替える顔テクスチャ（笑顔・びっくり・あれ？・大笑い・目かくし・あせり）。ロボットの顔は発光スクリーン（起動中の点・ハート・ぐるぐるエラー・スキャン）。
- カメラは場面ごとの固定ショットを自動で移動。画面の縦横比が変わっても、決めた範囲が入るように距離を計算する。
- 失敗はない。違う物を触ると「あれ？」の顔→喜ぶ。何もしない時間が続くと、半透明の手がやり方を見せる。
- 指の位置に女の子の手（お皿洗いではスポンジを持った手）を表示。
- 音は WebAudio で全部合成（チャイム・テープをはがす音・ロボットのピポ音・泡が割れる音・BGM）。iPhone のマナーモードでも鳴るよう `audioSession` を playback にしている。
- 遊び終わりの不意な再スタートを防ぐため、リスタートは長押しのみ。
- テスト用 URL パラメータ: `?scene=box|seek|kitchen|finale`、`speed=N`、`fastbox`、`fastdish`、`auto`（プレイ中の子どもには影響しない）。
- サムネイル `thumb.png` はロボットが箱から出た場面を実際のゲーム画面から撮影。

## 気になっている点
- 縦持ちの iPhone ではかくれんぼの部屋全体が小さく見える（当たり判定は広くしてある）。
- 泡の場面は泡を数百個描くので、古い端末では重くなるかもしれない（スマホでは個数を減らしている）。
