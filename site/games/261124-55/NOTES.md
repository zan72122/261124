# ガレージのはたらく車（261124-55）

5歳向け・文字なし・指1本の 3D ごっこ遊び。元ネタは子ども向け動画の「ミニカーが杖で本物になる／恐竜を巻き尺で測る」回。

## 遊びの流れ
0. **帽子えらび** — 道具の壁の前で、女の子に帽子（整備士キャップ／工事ヘルメット／運転手帽）をかぶせる。どれでも正解。服の色が変わり、手に星の杖が出る。以後、女の子は左下の丸窓にいて、表情（にこにこ・びっくり・「あれ？」・きりっ）で反応する。指は「女の子の手」で、タップした所に杖のとんとんが出る。
1. **ミニカー → 実物大**（ゴール＝6台ぜんぶ出発）
   - 最初にパパが金づちでミニカーをこつん → はね返って自分の頭にこつん、目が回って尻もち（大人の失敗ギャグ＝「金づちじゃだめ」）。
   - 看板の絵（小さい車＋杖 → 大きい車）がぴょこんと光ってルールを見せる。
   - ミニカーをとんとん → ガレージの外へ跳びながら実物大に。着地して自分の音（救急車ピーポー、パトカーのサイレン、バスはドアと止まれ板、ゴミ収集車はメロディ、ミキサーはドラム回転、ダンプは荷台）→ 出発。順番自由。
2. **はたらく車のおしごと**（ゴール＝3つの仕事）
   - 車がバックで並ぶ。パパがゴミ袋を山ほど運んでつまずき、ぜんぶこぼす（パパのやらかし）→ 女の子が「きりっ」。
   - ゴミ袋をタップ → ゴミ収集車がもぐもぐ食べる（5つ）。
   - まちがい：ボールを入れると「ぺっ」と吐き出してパパの手に → パパ「あれ？」→ にっこり（以後パパのボール遊び）。
   - ミキサー車をタップ → ドラムが回ってコンクリートを流す（3回で型枠がいっぱい。固まったら手形を押せる）。
   - ダンプをタップ → ピッピッとバックの音、荷台が上がって砂山ができる。
3. **恐竜の足あと**（ゴール＝巻き尺で2匹を測る → その後はずっと自由遊び）
   - どすん×3 で足あとが現れる。光る足あとを順にタップ（音階が上がる）→ 芝生のシートにおもちゃの恐竜とワニ。
   - 杖でとんとん → 実物大に。そばに大きな巻き尺。タップすると目盛り（線だけ、数字なし）が鼻先までのびる。2本が同じ線から並んでのびるので、長さの違いがひと目で分かる。
   - 最後は全部さわれる：恐竜（がおー・首ふり）、ワニ（ぱくぱく）、巻き尺（しまう／のばす）、車の音、コンクリートの手形、砂山、パパ、足あとの音階、女の子（くすくす）。右上の丸い矢印で最初から。

## 判断の記録
- **写実感**：three.js の PBR（クリアコート塗装・環境反射・やわらかい影・ACES トーンマップ）。道具の壁・床コンクリート・芝・遠景の家並みは画像生成した写真テクスチャ（数字入りメーターが写った1枚目は不採用にして作り直し、遠景は上端を空のグラデーションへぼかした）。車・人・恐竜はプリミティブで組み、顔は Canvas に描いて表情を差し替える。
- **主役の素材で画面を埋める**：ガレージの道具の壁から始まり、床のおもちゃ道路マット、ミニカー、実物大の車、工具の巻き尺、と最後まで同じ素材で通した。
- **カメラは自動**：場面ごとに寄る・引く・ついていく。指は画面内の物にだけ使う。
- **女の子は別レイヤー**：左下の丸窓に常時表示（帽子えらびの時だけ全面）。どの場面でも表情が見えることを優先した。左下は女の子に使うので、さわる物はそこに置かないよう配置した。
- **失敗なし**：外れたタップは白い波紋だけ。6.5 秒さわらないと次にさわる物に指のヒント。進みぐあいは上の星（文字・数字を使わない）。
- **怖くしない**：恐竜は首の長い草食の子で、目は大きく、ほっぺとにっこり口。ワニも歯なし・にっこり。どすんは低い音だけ。
- **ブランドなし**：救急車の印は赤丸に白い六角（実在の標章を避けた）、バスの止まれ板は文字なしの八角形。
- **音**はすべて Web Audio の合成（ファイルなし）。iOS は最初のタップで解錠。
- **縦持ち**でも視野角を広げて全体が入るようにした（横持ち／iPad が一番見やすい）。
- 確認用 URL パラメータ：`?skip=1|2|3`（その場面から）、`?fast`（遅い環境で時間を進める）。
